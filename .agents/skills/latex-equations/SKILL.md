# LaTeX 公式

生成含义明确、可编辑的公式代码，并融入用户现有的论文或 Beamer 文件。

## 判断任务类型

- **转录**：忠实复现图片或现有表达式，不静默修正原文、补推导或改换符号。
- **表达**：把自然语言写成公式，明确变量、定义域、索引、条件和单位；只补充表达所必需的假设。
- **推导**：仅在用户要求时展开，交代适用条件和关键等价变换；把推导与原始转录分开呈现。
- **排版**：保留数学含义，只调整环境、编号、对齐点和断行。

## 读取上下文与图片

1. 查看目标 `.tex` 的导言区、相邻公式、记号约定、编号和引用方式。
2. 沿用既有引擎、模板和数学宏包。此仓库为 XeLaTeX、ctex、PekingU、16:9 Beamer，不把该配置强加给其他项目。
3. 图片转录优先使用当前环境的内置视觉能力，直接检查用户提供的图片或可访问的局部放大图。
4. 特别核对上下标、分式范围、根号范围、负号、撇号、希腊字母、粗体和相似字符，如 `1/l/I`、`0/O`。
5. 图像确有歧义时列出具体位置与候选读法；先转录清晰部分，未确认的符号用醒目标记并在正文说明。
6. 不凭上下文猜成确定答案，不把模糊部分掩盖成正常公式；关键歧义影响含义时请用户确认或提供清晰局部。
7. 不要求专用 OCR API，不默认上传图片到第三方，也不声称调用过 Mathpix 等未实际使用的服务。

## 写出可编辑 LaTeX

- 优先复用已有宏定义和符号；新增宏只在重复表达确有收益时使用，并注明定义位置。
- 行内公式用 `\(...\)` 或项目现有约定；独立公式用 `equation`、`align` 等合适环境，避免 `$$`。
- 一组公式按等号或关系符对齐；单个编号的多行式用 `equation` 配合 `aligned` 或 `split`。
- 不把 `align` 嵌入 `equation`；排版已有公式时保留编号策略、`\tag` 和 `\label`，避免改变后续编号。
- 新增公式按项目习惯、引用需求和用户要求决定是否编号。
- 文字解释放在 `\text{...}`，已有标准运算符用 `\sin`、`\log` 等；新运算符按需用 `\operatorname`。
- 区分标量、向量、矩阵、集合、单位和文本下标，遵循论文已有记号，不擅自重定义字母。
- 分式、求和界限、条件概率和矩阵维度保持来源含义；转录中发现疑似错误时单独指出，不静默改正。
- 新标签采用唯一的 `eq:...` 名称；正文引用使用既有约定，必要时用 `\eqref`。
- 只添加实际需要的宏包，如 `amsmath` 或 `amssymb`；不为简单公式换引擎或引入庞大依赖。

## 页面适配与推导检查

- 按当前位置的 `\linewidth` 判断宽度，特别注意 Beamer 的分栏区域。
- 长式优先在有数学意义的位置断行，保留连接关系和必要括号，避免默认缩放整个公式。
- 不默认降到 `\tiny`；若一页无法清楚容纳，优先拆分推导步骤，同时保留用户要求的覆盖层顺序。
- 推导时检查定义域、分母非零、维度、索引范围及变形所需条件；不能凭一次数值代入宣称恒等式成立。
- 对只要求转录或排版的任务，不额外生成未经请求的证明、背景介绍或整篇改写。

## 验证与交付

1. 逐项对照来源，检查每个符号、上下标、界限、括号、矩阵行列和编号；图片中的明显歧义必须保留说明。
2. 检查花括号与环境配对、数学模式边界、宏命令依赖和重复标签。
3. 可用时按项目原构建方式编译；独立片段可用最小示例验证，不改动全局工具配置。
4. 检查编译错误、未定义引用与 overfull 警告；可渲染时查看断行、裁切和同页文字的实际间距。
5. 无法编译或查看图片时如实说明，区分已验证内容和待确认内容，不将公式代码等同于数学证明。
6. 返回代码及必要宏包；直接编辑时指出修改文件和位置，提供片段时说明导言区与正文各自的插入位置。
