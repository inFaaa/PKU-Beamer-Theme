# LaTeX 图文排版

以用户现有图片、图表或真实数据结果为依据完成排版，保留内容、比例和引用关系。
使用当前环境可用的文件、编译与 PDF 查看工具，不依赖特定插件或 API。

## 读取素材与页面

- 先检查主 `.tex`、现有宏包、目标 frame 或章节、图片文件及项目编译方式。
- 查看图片或 PDF 实际内容，确认尺寸、方向、白边及多页 PDF 中需要插入的页码。
- 分清用户需要插图、调整布局还是根据数据绘图；缺少图片或数据时明确指出，不能虚构图中结果。
- 延续现有图表的配色、标签和字号；不把普通排版扩展成重新设计整套报告。
- PKU-Beamer-Theme 默认使用 16:9 Beamer、单行双色页脚；其他项目沿用其实际配置。局部图文修改不改变全局主题或画幅。

## 图片与布局

- XeLaTeX 优先使用 PDF、PNG、JPG；矢量图优先保留 PDF，照片按原始栅格文件使用。
- EPS 仅在当前编译链需要时转换为 PDF，保留原文件，并检查转换是否丢失字体或内容。
- 使用 `graphicx` 的 `\includegraphics`；保持纵横比，同时限制宽高时加入 `keepaspectratio`。
- 不为铺满版面而拉伸图片或裁掉坐标轴、图例、文字；裁剪内容需要用户明确要求。
- 列内使用当前 `\linewidth` 控制图片、表格和文字宽度，避免误用整个页面的 `\textwidth`。
- Beamer 分栏优先沿用 `columns`/`column`；普通文章可用 `minipage` 或项目已有子图方案。
- 分栏总宽度加列间距不超过可用宽度；按内容选择顶部或垂直居中对齐。
- Beamer 中 `figure` 是图注和内容分组，不会像文章中的浮动体那样自动寻找位置。
- 不用反复堆叠 `[h]`、`[H]` 或负间距处理 Beamer 溢出，先调整局部布局和合理尺寸。
- 使用子图前检查已加载的宏包，沿用现有 `subcaption`、`subfig` 或手工编号方案，不混加冲突实现。

## 图注与引用

- 图注只描述素材支持的事实，保留单位、实验条件和用户要求的来源说明。
- 有编号图注时把 `\label` 放在 `\caption` 之后，保持既有引用键稳定且唯一。
- 沿用项目的 `\ref`、`\autoref` 或其他引用习惯，不手工写死图号。
- 子图分别引用时检查子图标签与总图标签；不需要独立引用时避免增加无用编号。
- 若图片内已有完整标题，按用户需求决定是否保留外部图注，避免重复占用空间。

局部插图可使用以下结构，尺寸按当前页面调整：

```tex
\begin{figure}
  \centering
  \includegraphics[width=\linewidth,height=.6\textheight,keepaspectratio]{pic/result.pdf}
  \caption{与实际图片对应的说明}
  \label{fig:result}
\end{figure}
```

## 验证与交付

- 按现有编译流程生成 PDF；交叉引用变化后再次编译至引用稳定。
- 检查日志中的缺图、未定义引用和 `Overfull`，再查看受影响的页面或 overlay。
- 视觉检查图中文字可读性、列间距、图注与页脚间距，确认没有遮挡、裁切或变形。
- 缺少编译或渲染能力时说明未完成的验证，不仅凭源码声称版面通过。
- 交付修改文件和生成的 PDF，简述布局变化及实际完成的检查；不附带无关主题改动。
