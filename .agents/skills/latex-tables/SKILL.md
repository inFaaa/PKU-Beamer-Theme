# LaTeX 表格

把用户的数据转为可核对、可继续编辑的 LaTeX；只修改所请求的表格及必要的宏包声明。

## 确认数据和插入位置

1. 读取用户提供的数据、目标 `.tex`、导言区和附近的表格样式。
2. 确认表头、行列顺序、单位、分组、脚注和空值含义；缺少的信息影响结果时再询问。
3. CSV 按实际分隔符和引号规则解析，保留引号内的逗号、换行、前导零和 Unicode 字符。
4. Markdown 按表格结构解析，注意转义的竖线和数学表达式，不把单元格内字符误当列边界。
5. 保留原始数值字符串、正负号、有效位数、百分号、缺失值和行列数量；空白不替换为零。
6. 用户没有要求计算时，不补算统计量、不排序、不合并数据，也不自动统一小数位。

## 生成表格

- 尊重现有编译引擎、文档类和模板。此仓库使用 XeLaTeX、ctex、PekingU 和 16:9 Beamer；其他项目沿用其配置。
- 默认用 `booktabs` 的 `\toprule`、`\midrule`、`\bottomrule`，遵循已有样式时保留明确要求的边框。
- 短表用 `tabular`；需要自动分配文本列宽时使用 `tabularx`，且仅在需要时加入宏包。
- 文本单元格转义 `&`、`%`、`#`、`_`、`$`、花括号等 LaTeX 特殊字符；反斜杠按文本用途处理。
- 先区分普通文本与已经存在的数学、命令和转义，不对整份源代码进行无差别替换。
- 保留明确给出的数学表达式及数学模式边界；不因为表头有下划线就擅自把文本改成公式。
- 数值按列对齐。只有确有需要时使用 `siunitx`，关闭非用户要求的舍入，并验证输入精度得到保留。
- 单位放在原有位置；用户同意统一单位前，不做换算或移动会改变含义的标签。
- 沿用目标文件的标题、编号和引用习惯；新 `\label{tab:...}` 应唯一，并置于对应 `\caption` 之后。
- 多级表头用必要的 `\multicolumn` 和 `\cmidrule` 表达，核对每一行实际占用的列数。

## 适配页面与 Beamer

- 用当前位置的 `\linewidth` 约束宽度；在 `column` 或 `minipage` 内不要按整页 `\textwidth` 设置表宽。
- 先调整列宽、长表头换行、单元格换行和适度列间距，再考虑局部字号。
- 不默认使用 `\tiny` 或将整表压缩到难以阅读；不要为了塞进页面删除列、截断数值或改写数据。
- 普通文稿的跨页长表可采用 `longtable`；Beamer 中不要嵌入跨页长表，按完整行组拆成续表并重复表头。
- 拆表时保留全部记录、单位、分组关系和必要脚注；不将一次表格修改扩展为整套幻灯片重排。
- 优先复用目标 `frame`，维持与同页图文的间距、对齐和覆盖层行为。

## 验证与交付

1. 对照输入逐行核查表头、记录数、列数、数值字符串、精度和缺失标记。
2. 检查 `&` 数量、行终止符、数学边界、分组跨度、宏包依赖和重复标签。
3. 有现成构建命令时按项目方式编译；否则在可用引擎下编译最小示例，不改动全局构建配置。
4. 检查未定义命令、引用和 overfull 警告。若可渲染，查看实际页面的边界、表头和脚注，确认无裁切。
5. 工具不可用时明确说明未编译，以及还需核对的内容；不要把语法检查表述为渲染通过。
6. 请求直接修改时提交精确修改；请求片段时给出完整代码、必要宏包及插入位置，不重复加载已有宏包。
